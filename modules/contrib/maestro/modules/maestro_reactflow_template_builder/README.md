# Maestro ReactFlow Template Builder

A submodule of [Maestro](https://www.drupal.org/project/maestro) that uses a [ReactFlow](https://reactflow.dev/) (@xyflow/react) powered visual template editor.

---

## Requirements

- Drupal 11+
- [Maestro](https://www.drupal.org/project/maestro) module

---

## Installation

1. Enable the module:

   ```bash
   drush en maestro_reactflow_template_builder
   ```
